## Critical blockers

1. The supplied 2005 scan has 53 questions; the last seven question texts must be recovered from a reliable source, not fabricated.
2. All candidate answers need independent review against the question text, options, and any necessary diagram, table, label, or menu.
3. Missing candidate letters must be resolved from academically sound supporting references and the original source context.
4. Current explanations require factual review and replacement wherever they are placeholder or weak.
5. Official-key evidence must be documented if the UI describes an answer as CXC-authenticated. Otherwise distinguish a SPARK-reviewed educational marking key from an official CXC mark scheme.
6. Exam scoring, correct-answer highlighting, explanation review, notification percentages, and parent/learning-intelligence grades must remain disabled for historical papers until the appropriate marking key has passed review.
7. Paper 02 is a separate structured-response marking project. This document inventories historical **Paper 01** only.

## Acceptance criteria for each historical paper

- Exactly 60 complete, correctly transcribed questions and four options per question.
- Every required diagram, table, menu and food label accurately represented.
- One sound answer per question, with a question-specific teaching explanation.
- Documented independent subject-matter check (and source-specific key evidence if claiming an *official* CXC answer).
- Passing automated structural/key tests and a manual exam scoring and result-reporting smoke test.
- No internal editorial QA notices on student-facing practice screens.
