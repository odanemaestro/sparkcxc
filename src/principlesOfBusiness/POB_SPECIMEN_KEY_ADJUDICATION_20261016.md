## Scoring contract

`pobSpecimenScoring.js` returns **two distinct results**:

1. **Printed-key comparison**: how many selected responses match CXC's printed key, out of all 60 for a full specimen or 10 for a checkpoint. It is shown as a source-comparison result, not a dispute-free academic grade.
2. **Uncontested learning score**: excludes any question marked `sourceKeyAcademicReview`. The full specimen denominator is **57**; Q31–40 is **9**; Q51–60 is **8**. The result identifies every excluded question. This is the fairer mastery diagnostic until authoritative clarification.

No automatic marking changes source answer letters; no new "official" grade or CXC correction is claimed. SPARK-generated explanations are labelled as pedagogical interpretation. Analytics retain both outcomes in metadata so they can be understood distinctly; future recommendation pipelines should prefer the uncontested score where available.
